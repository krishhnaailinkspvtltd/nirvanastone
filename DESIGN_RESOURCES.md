# Open-source UI/UX design research (4 November 2026)

These repos were researched for ideas; this project does not bundle their dependencies or source code.

| Repo | Link | Practical relevance |
|---|---|---|
| Anthropic Frontend Design | https://github.com/anthropics/skills/tree/main/skills/frontend-design | Distinctive art direction, typographic hierarchy and the avoidance of generic layouts. |
| Vercel Agent Skills | https://github.com/vercel-labs/agent-skills | Web design guidelines, performance and accessibility reviews. |
| shadcn/ui | https://github.com/shadcn-ui/ui | Accessible primitives for a future React-based checkout/admin interface. |
| Magic UI | https://github.com/magicuidesign/magicui | Reference patterns for tasteful animated accents and layout reveals. |
| Motion | https://github.com/motiondivision/motion | Spring interactions if/when migrating the frontend to React or using standalone JS animations. |
| React Three Fiber | https://github.com/pmndrs/react-three-fiber | WebGL 3D model viewers for products with genuine 3D assets. |
| Lenis | https://github.com/darkroomengineering/lenis | Optional smooth scrolling; intentionally omitted for reduced motion and small bundles. |
| Flowbite | https://github.com/themesberg/flowbite | Optional UI patterns for an administrative dashboard. |
| Next Ecommerce Shopco | https://github.com/mohammadoftadeh/next-ecommerce-shopco | Reference for an eventual full-featured commerce stack, not used as a template. |

**Style synthesis:** white/linen canvas, near-black plum ink, one restrained violet action accent, 28px product-card radius, rounded glass navigation, genuine product photography, deliberate typography, restrained motion, mobile-first product browsing.

**Licenses:** Review each repository's LICENSE before copying components or deploying code. This site currently uses only original CSS/JavaScript layouts and the uploaded photo assets, whose usage rights still require owner confirmation.
