# Shree Nirvan — Atelier IV

A static, nine-page responsive e-commerce UI/UX preview with independent logo, welcome animation, cinematic hero, interactive zodiac collection and product discovery.

Run `python3 -m http.server 8080` from this directory and open http://localhost:8080/. No build dependencies.

**Routes**: index.html, shop.html, zodiac.html, collections.html, product.html?id=..., wishlist.html, about.html, journal.html, contact.html.

**Design**: `css/atelier-v4.css` extends the original site styles; `js/atelier.js` adds an optional, reduced-motion-aware loading screen and reading progress. `assets/branding/` contains the logos and original decorative art.

**Demo only**: Prices are reference values, images from the supplied directory require usage rights review, and the cart prepares an enquiry rather than taking payment. Do not configure real checkout or claim certifications before validation.

See `DESIGN_SOURCES.md` for researched open-source references, and `ZODIAC_CATEGORY.md` for symbolic-benefit information.
