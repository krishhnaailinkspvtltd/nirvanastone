# Shree Nirvan — Atelier IV design references

This is an independently authored static storefront. No complete third-party template was copied, and no incompatible dependencies were added.

## Design research

- Anthropic frontend-design skill — https://github.com/anthropics/skills/tree/main/skills/frontend-design (design planning: distinctive art direction and typography)
- UI/UX Pro Max — https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (design tokens, component audit, accessibility and information hierarchy; MIT)
- Vercel agent skills — https://github.com/vercel-labs/agent-skills (web interface guideline review)
- Codrops — https://github.com/codrops (kinetic type and scroll-led storytelling as design inspiration)
- Lenis — https://github.com/darkroomengineering/lenis (smooth scroll study; MIT; deliberately *not* bundled because native scroll is more predictable on mobile)
- Anime.js — https://github.com/juliangarnier/anime (motion orchestration inspiration; independent CSS and JS animations are used for this site instead)
- React Three Fiber — https://github.com/pmndrs/react-three-fiber (3D performance reference, not installed in the vanilla JS website)
- Velora UI — https://github.com/ColorlibHQ/velora-ui (reduced-motion and accessible animated commerce patterns; not copied)

## Original implementation

- Bespoke SVG lotus + gemstone logo, exported to scalable assets
- 3D-style cinematic product scene with requestAnimationFrame pointer parallax
- Native animated zodiac orbit motif, interactive zodiac selector and dedicated 12-sign page
- Brand loading screen, readable progress indicator, kinetic typographic marquee, responsive collection cards, scroll-triggered reveal and browser-local wishlist/enquiry cart
- No unverified healing, financial, miracle or product certification promises
