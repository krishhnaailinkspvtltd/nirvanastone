# Deploy Studio Edition

## Vercel

This is a plain static site. Framework Preset: **Other**. Root directory: repository root. No install, build or output directory required. Keep `vercel.json` in the root.

## GitHub

Push the contents of this `site/` directory (not the entire original image archive) to the existing `nirvanastone` repository. Do not upload the unapproved `FULL_IMAGE_MATCHING_REVIEW.csv` as a public file; it is packaged only for the owner.

Once deployed, check `/`, `/shop.html`, `/collections.html`, `/product.html?id=ref-0019`, `/about.html`, `/journal.html`, `/contact.html`, `/wishlist.html`, mobile nav, search and enquiry cart.

This prototype has **no** live payment collection or server-side order handling.
